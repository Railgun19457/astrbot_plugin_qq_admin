# QQ群管

基于 **OneBot v11（aiocqhttp）** 的 QQ 群管理插件。仅支持 aiocqhttp 协议端。

## 功能

- **禁言 / 解禁**：支持 @ 目标、回复式、手打 QQ 号
- **全群禁言**：作为「禁言」的参数使用（`/禁言 全体`）
- **踢人**：可选同时拒绝其再次申请
- **撤回消息**：回复目标消息后使用 `/撤回`
- **多群分组**：多个群归为一组，组内共享黑名单
- **黑名单**：组级黑名单，拉黑后可自动拦截进群申请
- **进群审核**：关键词自动放行、黑名单自动拒绝、转人工确认
- **导出表格**：群成员名单、拉黑名单导出为 xlsx
- **LLM 工具**：以上能力可按需开放给大模型调用

## 安装

在 WebUI 的插件市场搜索「QQ群管」安装，或手动放入 `data/plugins/`。

依赖：`openpyxl`（导出表格用，安装插件时自动处理）。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/禁言 @某人 [时长] [理由]` | 禁言，时长支持 `10m` `2h` `1d`，省略则用默认值 |
| `/禁言 全体 [时长]` | 全群禁言，带时长时会自动解除 |
| `/解禁 @某人` / `/解禁 全体` | 解除禁言 |
| `/踢 @某人 [理由]` | 移出本群 |
| `/撤回` | 回复目标消息后使用 |
| `/群公告 [内容]` | 发送或查看群公告 |
| `/拉黑 @某人 [原因] [时长]` | 加入组级黑名单 |
| `/解除拉黑 @某人` | 移出黑名单 |
| `/黑名单` | 查看本组黑名单 |
| `/群成员` | 群成员概览 |
| `/群导出 成员` / `/群导出 黑名单` | 导出 xlsx 到群文件 |
| `/群管` | 查看指令帮助 |
| `/群管状态` | 查看运行状态与群组归属 |

## 权限

以下三种身份任一命中即可使用管理指令：

1. **AstrBot 全局管理员**（`admins_id` 或插件配置里的自定义白名单）
2. **群主 / 群管理员**（按 OneBot 的 `role` 字段判定）
3. **普通成员**（仅限查询类指令，可关闭）

每种能力的所需等级可在插件配置里单独调整。

## 注意事项

- **指令名改写**：如果本插件的指令与其他插件重名（同名指令会同时触发多个插件），
  请在 WebUI 的 **插件 → 管理行为** 中重命名或添加别名，无需改动插件配置。
- **指令与 `@` 之间要有空格**：`/禁言@某人` 不会被识别，请写成 `/禁言 @某人`。
- **协议端差异**：群公告 API（`_send_group_notice`）是协议端私有接口，
  部分实现不支持，此时会给出明确提示。建议使用 NapCat 或 Lagrange。
- **LLM 工具默认全部关闭**。框架对非内置工具的权限门控默认不拦截，
  开启前请确认你信任能触发模型的人。详见配置页的说明。
