# QQ 群管

![:name](https://count.getloli.com/@astrbot_plugin_qq_admin?name=astrbot_plugin_qq_admin&theme=miku&padding=7&offset=0&align=top&scale=1&pixelated=1&darkmode=auto)

基于 **OneBot v11（aiocqhttp）** 的 QQ 群管理插件，支持指令和 LLM 工具调用。

> 仅支持 `aiocqhttp` 协议端（如 NapCat、Lagrange）。其他平台不会响应。

## 功能

- 禁言、解禁、全群禁言
- 踢人、撤回消息
- 发送与查看群公告
- 黑名单管理，可选自动撤回黑名单成员消息
- 多群分组：组内共享黑名单与审核通知，每个群组可独立配置默认禁言时长、黑名单与进群审核策略
- 管理会话：群管理员专用的会话，接收审核通知并可直接处理申请、管理群组黑名单
- 进群审核：每个群组一套通用规则，关键词和跨群免审核支持用 `群号:` 前缀精确到群
- 导出群成员和黑名单为 Excel 并上传到群文件
- 审计日志
- 可按需向 LLM 开放管理工具（默认关闭）

## 安装

在 AstrBot WebUI 的插件市场搜索「QQ群管」安装，或将插件放入 `data/plugins/`。

插件依赖 `openpyxl`，安装时会自动处理。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/禁言 @用户 [时长] [理由]` | 时长支持 `600`、`10m`、`2h`、`1d` |
| `/禁言 全体 [时长]` | 全群禁言 |
| `/解禁 @用户` / `/解禁 全体` | 解除禁言 |
| `/踢 @用户 [理由]` | 移出群聊 |
| `/撤回` | 回复目标消息后撤回 |
| `/群公告 [内容]` | 查看或发送群公告 |
| `/拉黑 @用户 [原因] [时长]` | 加入黑名单 |
| `/解除拉黑 @用户` | 移出黑名单 |
| `/黑名单 [群号或群组名]` | 查看黑名单及原因；在管理会话中可用参数指定群组 |
| `/群成员 [页码]` | 查看群成员 |
| `/群导出 成员` / `/群导出 黑名单` | 导出 Excel 并上传到群文件 |
| `/审核 [列表]` | 查看待审核申请 |
| `/审核 同意 <编号>` / `/审核 拒绝 <编号>` | 处理进群申请 |
| `/群管` | 查看帮助 |
| `/群管状态` | 查看插件状态和群组归属 |

在管理会话（群组配置里的「管理会话」）中还可以使用：

| 指令 | 说明 |
| --- | --- |
| `/审核 [列表]` / `/审核 同意 <编号>` / `/审核 拒绝 <编号>` | 只看该群组的申请并对按编号处理 |
| `/黑名单 [群号或群组名]` | 查看该群组共享的黑名单 |
| `/拉黑 @用户 [原因] [时长]` / `/解除拉黑 @用户` | 维护该群组的黑名单（不会被误踢） |
| `/审核 通知设置 [群号或群组名]`（别名 `/黑名单 设置`） | 查看该群组的通知路由 |
| `/群管状态` | 查看该管理会话对应的全部群组 |

目标支持 `@`、回复消息和直接填写 QQ 号。时长参数可以放在任意位置；不带单位的数字仅在目标明确时按秒处理。

## 权限

管理指令默认允许以下身份使用：

1. AstrBot 全局管理员或插件自定义白名单
2. 群主、群管理员
3. 普通成员（仅查询类指令，默认开启）

每项能力都可以在配置中单独设置为「任何人」「群管理员」或「AstrBot 管理员」。

## 配置要点

插件只对「群组定义」里配置的群生效：同一群组内的群共享黑名单，并按群组配置禁言时长、黑名单与进群审核。单个群也可以单独建一个群组；「管理会话」可以留空，此时通知与管理都在群内完成。

- **群组定义**：填写群号列表；插件只对这些群生效。单个群也可以单独建一条群组，管理会话等留空即可。同一群组共享黑名单，可设置审核通知会话 UMO（在目标会话发送 `/sid` 获取）。
- **管理会话**：群管理员专用会话，填写在目标会话发送 `/sid` 得到的 UMO。审核通知默认发到这里；在其中可以直接执行 `/审核`（只看该群组的申请）、`/黑名单 [群号或群组名]`、`/拉黑`、`/解除拉黑` 与 `/群管状态`，其余指令会提示需在目标群内执行。留空时通知回退到申请所在群，全部管理仍在各群内完成。
- **默认禁言时长**：每个群组单独配置，未填写时长时使用，默认 `10m`。
- **黑名单**：每个群组可单独启用或关闭，并设置默认拉黑原因。黑名单撤回默认关闭；开启后会撤回黑名单成员发送的消息，但无法阻止其他插件或模型处理该消息。拉黑后自动踢出同样默认关闭，开启后在这一个群拉黑成功时会立即把目标移出当前群（从管理会话拉黑时不会踢人）。
- **进群审核**：每个群组配置一套通用规则与跨群免审核，可设置启用开关、关键词、黑名单拒绝、最低 QQ 等级、人工确认和无人值守时的处理方式。审核只对已加入群组的群生效，通知按「通知与回执」配置投递。
- **通知与回执**：内容按功能拆分，可分别选择发到当前会话、发到管理会话或两者都发，两个都不勾选则不发：`禁言`（含解禁与全群禁言）、`踢人`、`撤回`、`群公告`、`黑名单`（拉黑与解除拉黑）、`群导出`、`审核处理回执`（人工同意/拒绝的结果）、`进群审核通知`（自动放行/拒绝与转人工）。选择了管理会话但群组未配置时，会自动改发当前会话；在管理会话发送「审核 通知设置 [群号或群组名]」可随时查看某个群组当前的路由。
- **按群关键词**：关键词列表里直接写就是全群组通用；写成 `群号:关键词`（如 `123456:答案`）只对该群生效，两种写法可以混用。
- **跨群免审核**：直接填写来源群号（多个用逗号分隔）对所有群生效；写成 `目标群号:来源群号,来源群号` 只对指定目标群生效。申请加入目标群时，如果申请人已是来源群中任意一个的成员就直接通过，不再检查等级与关键词（黑名单仍然优先拒绝）。
- **LLM 工具**：默认全部关闭。开启前请确认对话用户可信，并建议在 WebUI「扩展 → 组件」中将工具设为 admin 级。

## 注意事项

- 插件只对「群组定义」里配置的群和管理会话生效；`/审核` 例外，可在任意群的群管权限下使用。
- 未纳入配置的群不会响应任何指令，消息会交给其他插件或模型处理。
- 指令需要在命令和参数之间保留空格，例如 `/禁言 @用户`。
- 群公告和 QQ 等级依赖协议端扩展；不支持时会提示或跳过对应校验。
- 全群禁言的定时解除由插件维护，并会在重启后恢复。
- 管理操作需要协议端具备对应权限。

## 数据文件

数据保存在 `data/plugin_data/astrbot_plugin_qq_admin/`，更新或重装插件不会丢失：

- `blacklist.json`：黑名单
- `audit.jsonl`：审计日志
- `pending_reviews.json`：待处理进群申请
- `whole_ban.json`：全群禁言定时记录
- `exports/`：导出的临时表格
